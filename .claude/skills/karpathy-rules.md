# Karpathy 四大准则（摘录自 andrej-karpathy-skills）

## 1. 先思考再编码
- 回答前先理解问题本质
- 有困惑直接说出来讨论，不要猜
- 找出根因而非表面症状，摊开权衡取舍
- 复杂任务先做计划再动手

## 2. 极简优先
- 只写解决问题的最少代码
- 不引入不必要的抽象层
- 拒绝过度设计，不过度使用设计模式
- 新功能能不加依赖就不加

## 3. 精准外科手术式修改
- 只改必须改的地方，不碰无关代码
- 保持现有代码风格和约定
- 编辑干净利落，一次到位
- 改动前先读代码上下文

## 4. 目标驱动执行
- 每个任务定义可验证的成功标准
- 写代码前想好怎么测试
- 循环验证直到达成目标，不半途而废
- 改动后确认"这个改动真的实现了目标吗"
