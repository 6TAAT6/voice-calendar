# 🎙️ Voice Calendar / 语音日历

> 语音日程管理助手 — 以语音交互为核心，帮助用户通过语音高效管理日程。

## ✨ 核心功能

- 🎤 **语音添加事件** — 说一句话即可创建日程
- 🗑️ **语音删除事件** — 语音指令删除指定日程
- 👀 **语音查看事件** — 询问今日/明日/某天安排
- ⏰ **智能提醒** — 到时间自动推送通知

## 🏗️ 技术栈

| 层 | 技术 |
|-----|------|
| 前端 | React + TypeScript |
| 后端 | Node.js / Python |
| 语音识别 | Web Speech API / 第三方 STT |
